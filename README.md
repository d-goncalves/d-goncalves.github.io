# diogog.com

My personal website: a single plain HTML page (`index.html`) with inline CSS, no build step and no JavaScript.

## Files

- `index.html`: the page.
- `cv.pdf`: my CV. Don't edit it here; it is built from the private CV repo, whose GitHub Action commits a new `cv.pdf` here whenever the CV changes.
- `assets/favicon/`: the cactus icon (`favicon.svg` is the source; the `.ico` and the Apple touch icon are generated from it).
- `CNAME`: the custom domain for GitHub Pages. Removing it takes the domain off the site.

## Editing

Open `index.html` in a browser to preview it. Pushing to `main` publishes it through GitHub Pages.
